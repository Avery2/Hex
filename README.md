# Hex (Swift Fork)

A fork of the original Swift Hex with live transcription, clearer recording feedback, and improved reliability.

## Improvements

- **Live transcription:** See your words appear in real time as you speak.
- **Clearer recording feedback:** An explicit listening state makes it obvious when recording actually begins.
- **Fewer dropped words:** Fixes premature recording cutoffs and missing words at the end of recordings.
- **More resilient recovery:** Better preservation of transcripts when recording is interrupted or the app crashes.
- **Improved transcript history:** Easier to find and copy previous recordings, including transcripts that were never pasted.

## About This Fork

This fork builds on the original Swift version of [Hex](https://github.com/kitlangton/Hex), with a focus on usability and reliability.

The upstream project has since moved to [Rust](https://github.com/anomalyco/hex).
